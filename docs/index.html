transcript-to-okf (v1.0.0)

Zero-dependency, 100% offline CLI and Node.js ESM library to migrate transcripts from Otter.ai, Plaud Note / Desktop, HiNotes (HiDock), Notta, Microsoft Teams / Zoom WebVTT, and SRT into deterministic Google Open Knowledge Format (OKF v0.2) Markdown vaults.

brew tap onemira-space/tap && brew install transcript-to-okf
transcript-to-okf --in ./exports --out ./ObsidianVault/Meetings
